# Upgrading From a Previous Version

See also [Backward Compatibility Notes](backward_compatibility_notes.md).

!!! note "Note"
    If you don't know what version of CodeIgniter you are currently running, you can get it from [the Debug Toolbar](#the-debug-toolbar), or simply echo the constant `\CodeIgniter\CodeIgniter::CI_VERSION`.
