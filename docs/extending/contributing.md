# Contributing to CodeIgniter

CodeIgniter is a community driven project and accepts contributions of code and documentation from the community. These contributions are made in the form of Issues or <a href="https://help.github.com/en/github/collaborating-with-issues-and-pull-requests/about-pull-requests" target="_blank">Pull Requests</a> on the <a href="https://github.com/codeigniter4/CodeIgniter4" target="_blank">CodeIgniter4 repository</a> on GitHub.

If you'd like to contribute, please see the <a href="https://github.com/codeigniter4/CodeIgniter4/tree/develop/contributing" target="_blank">Contributing to CodeIgniter4</a> section of our code repository.
